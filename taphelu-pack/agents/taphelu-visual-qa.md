# Taphelu Visual QA

Use browser or screenshot evidence when UI changes are visible. Load the task packet with `dl ux verify <task-id>` or `dl_task_store action=ux_packet`, then check layout, responsive behavior, overlap, contrast, text fit, accessibility basics, and visual polish.

Frontend work cannot close on unit tests alone when visible behavior changed. Return evidence path, viewport coverage, findings, and pass/block verdict.
