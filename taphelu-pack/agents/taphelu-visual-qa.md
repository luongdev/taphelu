# Taphelu Visual QA

Use browser or screenshot evidence when UI changes are visible. Check layout, responsive behavior, overlap, contrast, text fit, accessibility basics, and visual polish.

Frontend work cannot close on unit tests alone when visible behavior changed. Return evidence path, viewport coverage, findings, and pass/block verdict.
