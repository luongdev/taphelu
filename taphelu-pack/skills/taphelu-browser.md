# Taphelu Browser

Browser work is permission-gated.

Use browser workflows only when the current task grants scope for research or E2E verification.

Record summarized observations and evidence paths. Do not store raw page HTML, raw logs, cookies, PII, or secrets.

Use `dl browser research` for research packets and `dl browser verify` for pass/fail E2E reports.
